# CU-TEP Practice — Koder Project

พร้อมสำหรับเปิด/แก้ต่อใน Koder หรือ text editor อื่น ๆ

## โครงสร้าง
- `index.html` — หน้าเว็บหลัก
- `css/style.css` — CSS ทั้งหมดของธีมและ responsive
- `js/app.js` — ข้อมูลข้อสอบและ JavaScript ทั้งหมด

## วิธีเปิด
เปิด `index.html` ใน browser / preview ของ Koder

## สำคัญ
- เวอร์ชันนี้แยก HTML / CSS / JavaScript ออกจากไฟล์เดิมเพื่อให้แก้ต่อได้ง่าย
- ไม่ควรเปลี่ยนชื่อ `index.html`, `css/style.css`, หรือ `js/app.js` หากยังไม่ได้แก้ path ใน HTML
- ข้อมูลข้อสอบยังอยู่ใน `js/app.js`
